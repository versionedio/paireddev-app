Logic Blocks · Glyphs · Agents · Automations

The behaviour layer

Entities hold data; these assets decide what is allowed. Logic Blocks are the default. A Glyph is used only where a real programming language is needed. Crews are used only where an agent needs tools or a human pause.

1 · Naming blocks for access control

A user's route policy is cached and capped near 8 KB — roughly 12 individually named blocks. We have ~55, so blocks carry a tier prefix and ACL policies grant by prefix (pd_dev_*) instead of listing names.

To verify at build time: the exact route/action name a Logic Block gets (for example createpd_dev_get_item vs another shape). Create one block, then read list_tenant_acl_policies before writing the wildcard statements. The ACL guide only documents the convention for entities.

4 · Agents (Crews) and AI calls

A single model call is an ai_call step. A Crew is used only where an agent needs tools or may need to pause. In every case the crew returns its result and a Logic Block writes the record, so a crew never has a back door into governed tables.

CapabilityMechanismProviderNotes
Triage: impact, effort, categoryai_call (json out) inside a loopTenant default; Gemini or AnthropicRequirement 7 allows Google for triage, scoring, summaries. Tags and composite score are formula steps.
Plan PreviewCrew pd-plannerProject exec_provider (Anthropic)Read-only tools. Revision loop is a block, not a crew graph.
Coding sessionConnector muse-code on a GitHub runnerAnthropic via the connector's ai_provider / ai_modelSee G-01.
Checklist pre-checkCrew pd-checklist-reviewerAnthropicOutput feeds record_precheck. Comments reach GitHub as COMMENT only.
Release / delivery pre-flightCrew pd-preflightAnthropicMust say when it stops: ordering a release is a product call.
Retro digestai_call summarizeTenant defaultGroups are computed; the model writes only the one-line note per group.

Crew lifecycle: created as draft, then staged → active with update_crew. Only active crews can be invoked, so the build plan includes the promotion step. Each agent node can name a tenant provider; a provider the tenant lacks fails clearly rather than falling back.
