2 · Entity catalogue

Column types use nostackai names: string number boolean date enum lookup formula autoincrement. JSON-shaped values are stored as string and parsed by blocks. “Writes via” says which route may change the table; “direct” means the entity's own REST route is allowed for permitted roles.

4 · Governed tables

For these, every role's direct create / update / delete is denied in ACL. Only Logic Blocks write them.

work_itemchecklist_itemplanagent_sessionsession_stepsession_gatehookpermission_cellaudit_eventlane_transitionrepo_event

Reads are open to the roles that need them. The remaining tables (project_group, notification_pref, …) are plain CRUD for permitted roles.
